SOFTWARE FJ

Sistema de gestión de clientes, servicios y reservas

1. Descripción del proyecto

Software FJ es una aplicación desarrollada en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.

El sistema permite registrar clientes, consultar información, crear reservas y administrar sus estados.

2. Objetivo

Desarrollar un sistema que aplique los principios de programación orientada a objetos, incluyendo abstracción, herencia, encapsulamiento, polimorfismo y manejo de excepciones.

3. Funcionalidades

- Registro y consulta de clientes.
- Validación de datos personales.
- Gestión de servicios de alquiler de salas.
- Gestión de alquiler de equipos.
- Gestión de asesorías especializadas.
- Cálculo de costos con impuestos y descuentos.
- Registro y consulta de reservas.
- Confirmación, cancelación y procesamiento de reservas.
- Manejo de excepciones personalizadas.
- Registro de eventos, errores y advertencias.

4. Tecnologías utilizadas

- Lenguaje de programación: Python.
- Editor de código: Visual Studio Code.
- Control de versiones: Git.
- Repositorio: GitHub.

5. Estructura del proyecto

main.py  ----  Programa principal y menú de opciones. 
entidades.py  ----  Clases Entidad y Cliente. 
servicios.py  ----  Clase abstracta Servicio y servicios especializados. 
reservas.py  ----  Gestión de reservas. 
excepciones.py  ----  Excepciones personalizadas. 
logs.py  ----  Registro de eventos y errores. 
pruebas.py  ----  Pruebas generales del sistema.
